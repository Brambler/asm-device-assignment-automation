# Presentation slides

**Automating device assignments in Apple Business/School Manager: Using the AxM API**

[Download the slides (PDF)](Automating_Device_Assignments_in_ASM.pdf)

## What's covered

1. **Before the ability to automate.** WVU's decentralized IT, 17+ Jamf Pro sites and ASM servers, and the old email-to-ticket-to-technician process.
2. **How the API changed the game.** What the Apple School and Business Manager API from WWDC 2025 made possible: finding devices and moving them between MDM servers.
3. **Automating device assignments at scale.** Capturing order data, matching orders to purchasers, mapping purchasers to support units and Jamf Pro sites, and Teams notifications.
4. **Impact.** Results from the first six months in production.
